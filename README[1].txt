JEETMANYU SHARMA — STUDENT PORTFOLIO

FILES
- index.html  : page structure and content
- style.css   : responsive styling and layout
- script.js   : mobile navigation, scroll progress, reveal effects

HOW TO RUN
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Open index.html in a browser.
   Recommended: use VS Code + Live Server while editing.

IMPORTANT PERSONALISATION
Before publishing, update:
- your.email@example.com with your real email in index.html
- GitHub and LinkedIn profile links
- project descriptions, screenshots, and repository links
- education details (expected graduation year, CGPA, coursework)
- skill list so it reflects what you can confidently demonstrate

The two project cards are starter examples based on common student learning areas.
Replace them with your own completed work before presenting the portfolio publicly.
